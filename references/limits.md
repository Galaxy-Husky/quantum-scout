# 限制与预算

适用于 v14 新执行。数值分为资源预算、领域规则与上游容量；提高资源预算不提高证据质量。
本次已直接修正默认预算和确定性边界，未改写历史 workspace、配置或执行基线。

## 已执行的调整

| 项目 | 修前 → 当前 | 依据 |
|---|---|---|
| 隐式模型调用 | 8 → 64 / invocation | 完整八字段至少17次；单案例五表全部27单元理想需59次，保留少量余量 |
| 隐式任务轮次 | 2 → 5 / invocation | 每轮领取一个表任务；两条 Track 共问题定义、两个准入、两个评分表 |
| 隐式总时间 | 300 → 1200秒 / invocation | 与64次有限调用配套；单调用仍60秒，不承诺64次都能完成 |
| 手工下载大小边界 | 恰等于上限也失败 → <=上限成功 | 10字节上限接受9/10，拒绝11；不放大100MiB默认值 |
| 手工下载参数/重试 | 隐式容错 → max_bytes>0、retries仅0/1 | 无效参数不发请求；HTTP错误不重试，传输异常最多额外一次 |
| 正文解析截止 | 同步阻塞 → HTML线程/PDF异步子进程 | 外层超时可生效，PDF取消清理子进程；线程只读且取消后不提交来源 |
| 元数据响应 | 无字节上限 → 2,000,000字节 | 元数据非正文；流式限长，超限unknown并留明确标记的前缀，不重试 |
| 接受分数 | 部分导出硬编码15 → 配置快照阈值 | 自定义门槛贯穿停止、验收和报告；旧批次缺快照时才回退15 |

64次不是完整运行保证。一个抽取可能使用多次ContextGem请求，还可能涉及分段、纠错、失败、
额外来源或多个案例。只有一条 Track 合法完成链即可覆盖停止；准入拒绝/显式不适用也会改变成本。
八字段全为新支持证据时需至少1次抽取+16次复核=17；单Track准入拒绝的理想下界26，
准入通过后NLC最少4维约35次、安全最少5维约37次；两个Track全部单元59次。
这些是理想请求下界，不是服务价格估计。既有显式小预算继续有效，doctor提示部分校准。
不自动扩大配置、循环恢复或因预算耗尽补造证据。本次修改本身不调用模型。

## 运行和累计范围

| 限制 | 默认/契约 | 范围与判断 |
|---|---|---|
| 模型/轮次/时间 | 64 / 5 / 1200秒 | 每次显式invocation；历史累计单列，恢复仍需原配置 |
| 单操作超时 | 60秒 | 被剩余总时间夹取；不保证硬实时，文件持久化和只读HTML线程可能稍后结束 |
| 每轮新来源 | 2 | 调度配额；失败不等于无证据，未处理来源保留 |
| 搜索结果 | 3，配置最多10 | 单查询有界结果集，不分页、不证明搜索穷尽 |
| 正文上下文 | 40000字符 | 仅segment字符，不含提示词/ledger，不是总token预算；整段放不下明确失败，不静默截断 |
| 模型输出 | min(共享配置,4096) token | 有限输出成本；长结构仍可能截断，契约错误必须留痕 |
| SDK/格式修复 | SDK重试0；格式纠错最多1次 | 修复与ContextGem退路均计入调用预算，不保证抽取仅一次请求 |
| 收益递减窗口 | 3 | 观察已搜索查询，可能跨显式恢复；不是语义充分或全局穷尽 |
| analysis_limit | 20 | workspace累计成功打开的去重正文；不代表所有表/分段已处理，优先停止时仍报告缺口 |
| max_cases | 10 | workspace累计达标案例上限，不是配置案例数量上限 |
| batch_size | 5 | 导出间隔，不影响逐事实持久化，终止仍保存checkpoint |
| 引用HTTP | 20 | workspace累计，身份与扩展共用；重试分别计数，缓存命中0，默认引用服务关闭 |
| 传输恢复 | 每查询/来源最多1次显式恢复；引用最多1次预算内重试 | 不重试HTTP状态错误；429暂停引用服务，缓存与原失败保留 |

## 网络、解析与容量

| 限制 | 值 | 判断 |
|---|---|---|
| 在线正文 | 20,000,000字节；下载30秒 | 与手工缓存100MiB入口不同；超限明确失败，不证明不存在 |
| 正文跳转 | 最多6次HTTP尝试 | 当前循环最多跟随5次跳转后成功；不是允许无限重定向 |
| PDF解析/可读下限 | 30秒；至少100字符 | 过滤空/不可读内容的启发式，不保证正文完整，也可能拒绝极短文档 |
| 手工缓存 | 100MiB；30秒/请求；0或1次重试 | 与在线策略分别配置；arXiv重试至少3.1秒，其他2秒 |
| 引用HTTP | 20秒/请求；元数据2MB | 同时受剩余运行时间/单操作预算约束，不保证多服务全完成 |
| 服务间隔 | arXiv>=3.1秒；其他>=1秒 | 单workspace持久节流锚点；多项目需协调总访问率；免费服务仍需要请求/时间限制 |
| 引用扩展 | depth=1；每FILLED父节点最多5新任务 | 每方向最多取5候选，可先有10条再去重/裁至5；线索不作事实 |
| 引用HTTP放大 | S2通常2次；OpenAlex最多7次/根 | 不含可能的身份请求/传输重试；5个任务不等于5个HTTP请求 |
| Frontier | 上游200任务 | 每案例5基础任务；40案例满容，无引用余量，41明确拒绝。保持容量，按批新建workspace |
| phase规划 | full目标200案例 | 不自动映射单在线workspace；不能一次塞进Frontier，phase也不自动提高预算 |
| 字符串执行器 | 10秒；上游输出2MB/stdout16k | 小型字符串门输出；正文大不意味着需要扩大执行器输出 |

## 领域与结构限制

| 限制 | 值 | 判断 |
|---|---|---|
| 候选/引文 | 每次最多8候选；短引1–50字符 | 当前最大表8字段；保留原文跨度，不放行OCR或NFKC数字改写 |
| 反证 | 短引<=50；summary<=2000字符 | 真值项/矛盾绑定实际分段和短引；不保证语义充分 |
| 查询/标题 | 生成查询<=1000字符；书目比对<=4000字符 | 避免无界输出与编辑距离开销；用户种子不属于模型Query输出 |
| 标题相似度 | >=0.70 | 仅元数据启发式；不证明正文支持，不能复用于正文接地 |
| 评分 | 1/3/5；归一25；当前门槛15 | NLC最少4有效维、安全最少5；用配置阈值，领域门槛未经新证据不擅改 |
| 人工抽查 | 至少10%且至少3；不足取全部；<5%严重提示 | ceil取整；机器覆盖不依赖人工标签，不把小样本外推成准确率 |
| 观察窗口 | 10个独立workspace快照 | 观察不足不判逻辑不可达，不因未触发就删分支 |

默认值是有限执行策略；目前没有真实语义/成本基准证明其最优。新增问题应通过失败回执、
可复现边界或用户明确范围来调整，不能靠提高数字解决归属、语义、反证或版本冲突。
